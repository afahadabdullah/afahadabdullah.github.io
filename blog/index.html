00 ClimBuntu OS

ClimBuntu (Climate + Ubuntu) is a free Linux distribution I built for climate research — numerical climate models (WRF, MITgcm, SPEEDY), geospatial tools (QGIS), and the scientific Python stack, all preinstalled and ready to run. It removes the setup barrier so students and researchers can get straight to the science.
